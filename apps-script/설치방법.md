# 웹툰트리 서버(Apps Script) 설치 방법

이 서버를 연결하면 회원가입·로그인, 함께 보는 별점·댓글, 계정에 저장되는 감상 진행·코인, 친구 랭킹, 오늘 폭주, 관리자 잠금 해제, 새 화 제보, 주간 알림 메일이 켜져요.
처음 한 번만 하면 되고, 15분쯤 걸려요.

## 1. 구글 시트 만들기

1. [sheets.new](https://sheets.new) 에 들어가 새 구글 시트를 만들어요.
2. 왼쪽 위 제목을 `웹툰트리 데이터`로 바꿔요.
3. 이 시트에 회원 정보가 저장되니 **다른 사람에게 공유하지 마세요.**

## 2. 코드 넣기

1. 시트 메뉴에서 **확장 프로그램 → Apps Script**를 눌러요.
2. 처음 있는 `function myFunction() {}` 을 모두 지워요.
3. 저장소의 `apps-script/Code.gs` 내용을 전부 복사해서 붙여 넣어요.
4. 위쪽 저장 아이콘(💾)을 눌러요. 프로젝트 이름은 `웹툰트리 서버`로 하면 돼요.

## 3. 비밀 값 넣기 (스크립트 속성)

1. 왼쪽 톱니바퀴 **프로젝트 설정**을 눌러요.
2. 맨 아래 **스크립트 속성 → 스크립트 속성 추가**에 아래 값을 넣고 저장해요.

| 속성 | 값 | 꼭 필요? |
| --- | --- | --- |
| `ADMIN_PASSWORD` | 관리자 비밀번호 (남이 못 맞힐 만큼 길게) | 필수 |
| `ADMIN_EMAIL` | 주간 알림을 받을 메일 | 선택 (비우면 내 구글 메일) |
| `ADMIN_ID` | 사용자 사이트 로그인 화면에서 관리자로 들어갈 아이디 | 선택 (비우면 `admin`) |

비밀번호는 코드에 쓰지 않고 여기에만 넣어요. 그래서 사이트 코드를 누가 열어 봐도 보이지 않아요.

## 4. 처음 한 번 실행하기

1. 왼쪽 **편집기(< >)**로 돌아가요.
2. 위쪽 함수 선택 칸에서 `setup` 을 고르고 **실행**을 눌러요.
3. "권한 검토"가 뜨면 내 구글 계정을 고르고 → **고급 → 웹툰트리 서버(으)로 이동(안전하지 않음)** → **허용**을 눌러요.
   내가 만든 코드라 구글이 아직 확인하지 않았다는 뜻이에요.
4. 시트에 `users`, `sessions`, `ratings`, `comments`, `views`, `coinLog`, `reports` 탭이 생기면 성공이에요.

## 5. 웹앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포**를 눌러요.
2. 톱니바퀴(유형 선택)에서 **웹 앱**을 골라요.
3. 설정:
   - 설명: `웹툰트리 서버`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포**를 누르고, 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해요.

## 6. 사이트에 주소 넣기

1. [관리자 화면](https://hy3ongh0.github.io/webtoontree/admin.html) → **디자인 · 코인 설정** → "Apps Script 웹앱 주소"에 붙여 넣어요.
2. **데이터 내보내기**에서 data.json을 내보내 GitHub `data` 폴더에 올려요.
3. 1~2분 뒤 사이트 첫 화면에 **로그인 · 회원가입**이 나오면 연결 끝이에요.
4. 관리자 화면 **회원 · 댓글 · 제보** 탭에서 관리자 비밀번호로 연결해 보세요.

## 7. (선택) 관리자 화면에서 [바로 저장] 쓰기

파일을 GitHub에 올리지 않고 관리자 화면 버튼 하나로 반영하려면:

1. GitHub → 오른쪽 위 프로필 → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
2. Repository access: **Only select repositories → webtoontree**
3. Permissions → Repository permissions → **Contents: Read and write** (다른 권한은 건드리지 않아요)
4. 만료 기간을 정하고 생성한 뒤 토큰을 복사해요 (다시 볼 수 없어요).
5. Apps Script **프로젝트 설정 → 스크립트 속성**에 `GITHUB_TOKEN` 으로 넣어요.
6. 관리자 화면 **데이터 내보내기** 탭의 **지금 내용으로 사이트에 바로 저장** 버튼이 켜져요.

토큰은 이 저장소의 파일만 바꿀 수 있게 만들었으니, 혹시 새어 나가도 다른 저장소는 안전해요. 그래도 남에게 보여 주지 마세요.

## 코드를 고친 뒤 다시 배포하기

`Code.gs`를 새 버전으로 바꿨다면:

1. 코드를 붙여 넣고 저장해요.
2. **배포 → 배포 관리** → 연필(수정) → 버전: **새 버전** → **배포**
3. 이렇게 하면 웹앱 주소가 그대로라 사이트를 고칠 필요가 없어요. ("새 배포"를 누르면 주소가 바뀌어요.)

## 사용자 사이트에서 관리자로 들어가기

사이트 로그인 화면에서 아이디에 `admin`(또는 `ADMIN_ID`에 넣은 값), 비밀번호에 `ADMIN_PASSWORD`를 넣으면 관리자 화면의 [회원 · 댓글 · 제보] 탭으로 바로 가요.
관리자 비밀번호는 그 브라우저 탭에서만 기억하고, 탭을 닫거나 [관리자 나가기]를 누르면 잊어요. 일반 회원은 이 아이디로 가입할 수 없어요.

## 여러 관리자와 같이 작업하기

- `admin` 계정이 **최종 관리자**예요. 관리자 비밀번호는 최종 관리자만 알고 있으면 돼요.
- 함께 작업할 사람은 사이트에서 평소처럼 회원가입해요.
- 최종 관리자가 관리자 화면 → [회원 · 댓글 · 제보] → 회원 목록에서 **관리자로 지정**을 두 번 눌러요. 빼려면 **관리자 해제**를 눌러요.
- 지정된 사람은 자기 아이디로 로그인한 뒤 **내 정보 → 관리자 화면 열기**로 들어와요.
- 관리자 회원이 할 수 있는 것: 웹툰·장르·트리·지도·상점 편집, 바로 저장, 댓글 숨기기, 제보 처리, 일반 회원 정지·닉네임 변경, 잠금 해제
- 최종 관리자만 할 수 있는 것: 관리자 지정·해제, 비밀번호 초기화, 다른 관리자 계정 정지·닉네임 변경
- **함께 편집(실시간):** 관리자 화면에 연결되면 모두가 같은 초안을 같이 고쳐요. 다른 관리자가 고친 내용이 2~4초 안에 내 화면에 반영되고, 위쪽에 누가 어디를 고치는 중인지 보여요. 서로 다른 웹툰·트리 위치·설정을 고치면 모두 남고, 같은 칸을 동시에 고치면 나중에 고친 사람 것이 남아요.
- 바로 저장을 누르면 모두가 함께 고친 내용이 사이트에 올라가요. GitHub 기록에는 누가 올렸는지 남아요.
- 함께 편집 기록은 시트의 `live` 탭에 쌓이고, 사이트에 올릴 때마다 정리돼요.
- 시트의 `users` 탭 맨 오른쪽에 `role` 칸이 생겨요. 처음 요청이 들어올 때 자동으로 생기니 직접 만들 필요는 없어요.

## 매주 알림 메일

`setup`을 실행하면 매주 **월요일 오전 9시**에 메일이 와요.

- 새 화 제보가 들어온 웹툰
- 연재 중인 웹툰과 지금 계산된 총 화수 (휴재 등으로 어긋난 것 확인용)
- 휴재 중인 웹툰

8일이 지난 조회 기록(오늘 폭주 계산용)도 이때 정리돼요.

## 알아 두면 좋은 것

- 회원 비밀번호는 회원마다 다른 랜덤 값과 섞어 여러 번 해시해서 저장해요. 시트 주인(관리자)도 원래 비밀번호는 볼 수 없어요.
- 코인과 랭킹 계산은 모두 서버에서 해요. 하루에 인정되는 화수는 관리자 설정의 상한을 따라요.
- 구글 Apps Script는 무료 계정에도 하루 사용량 한도가 있어요. 학교 친구들끼리 쓰는 정도는 충분하지만, 사람이 아주 많아지면 느려질 수 있어요.
- 서버를 연결하기 전에 "닉네임으로 시작"으로 쌓은 기록은 그 브라우저에만 있어서 계정으로 옮겨지지 않아요. 연결 후 회원가입해 주세요.
