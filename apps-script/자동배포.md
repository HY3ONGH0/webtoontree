# 서버(Apps Script) 자동 배포 설정

한 번만 설정하면, 서버 코드(`apps-script/Code.gs`)가 바뀐 PR을 합칠 때마다 GitHub가 알아서

1. Apps Script에 새 코드를 붙여 넣고
2. **배포 → 배포 관리 → 연필 → 새 버전 → 배포**를 하고 (주소는 그대로)
3. 서버가 새 판 번호로 응답하는지 확인해요.

설정 전에는 이 자동 배포가 그냥 건너뛰어요 (실패로 뜨지 않아요). 지금처럼 `server-code.html`로 손으로 배포해도 돼요.

필요한 것: **Apps Script 프로젝트를 만든(배포한) 구글 계정**, 그리고 명령어를 한 번 칠 곳(아래 방법 A나 B).

---

## 1. Apps Script API 켜기 (아이패드에서 돼요)

1. https://script.google.com/home/usersettings 을 열어요 (Apps Script 프로젝트를 만든 구글 계정으로).
2. **Google Apps Script API**를 **사용**으로 바꿔요.

## 2. 스크립트 ID 복사하기 (아이패드에서 돼요)

1. 웹툰트리 구글 시트 → **확장 프로그램 → Apps Script**
2. 왼쪽 **톱니바퀴(프로젝트 설정)** → **스크립트 ID** 옆 **복사**
3. 메모장에 잠깐 붙여 둬요.

## 3. 로그인 정보 만들기 (명령어를 한 번 쳐야 해요)

### 방법 A: 아이패드에서 GitHub Codespaces 쓰기

1. https://github.com/HY3ONGH0/webtoontree 에서 초록 **Code** 단추 → **Codespaces** 탭 → **Create codespace on main**
2. 화면 아래 **터미널**에 다음을 붙여 넣고 실행해요:
   ```
   npx -y @google/clasp@3.4.1 login --no-localhost
   ```
3. 나온 긴 주소(`https://accounts.google.com/...`)를 눌러 열고, **Apps Script 프로젝트를 만든 구글 계정**으로 로그인 → **허용**
4. 다음 화면이 "연결할 수 없음"(localhost) 오류로 떠도 괜찮아요. **그 페이지의 주소창 주소 전체**를 복사해요 (`http://localhost:8888/?code=...`).
5. 터미널로 돌아와 그 주소를 붙여 넣고 엔터 → `Authorization successful`이 나오면 성공이에요.
6. 다음을 실행해서 나온 글 전체를 복사해요 (`{`로 시작해서 `}`로 끝나요):
   ```
   cat ~/.clasprc.json
   ```
7. 다 쓴 Codespace는 https://github.com/codespaces 에서 **Delete**로 지워요 (로그인 정보가 남지 않게).

### 방법 B: 컴퓨터(윈도우 · 맥)에서

[Node.js](https://nodejs.org)가 깔린 컴퓨터의 터미널(명령 프롬프트)에서:
```
npx -y @google/clasp@3.4.1 login
```
브라우저가 열리면 Apps Script 프로젝트를 만든 계정으로 허용하고, `~/.clasprc.json`(윈도우는 `C:\Users\내이름\.clasprc.json`) 파일 내용을 전부 복사해요.

## 4. GitHub에 비밀값 두 개 넣기 (아이패드에서 돼요)

1. https://github.com/HY3ONGH0/webtoontree/settings/secrets/actions 를 열어요.
2. **New repository secret**
   - Name: `CLASPRC_JSON` / Secret: 3번에서 복사한 글 전체 → **Add secret**
3. 다시 **New repository secret**
   - Name: `GAS_SCRIPT_ID` / Secret: 2번에서 복사한 스크립트 ID → **Add secret**

배포 ID는 따로 넣지 않아도 돼요. 사이트 설정의 서버 주소(`.../macros/s/배포ID/exec`)에서 읽어요.

## 5. 한 번 돌려 보기

1. https://github.com/HY3ONGH0/webtoontree/actions/workflows/deploy-server.yml
2. **Run workflow** → **Run workflow**
3. 1~2분 뒤 초록 체크가 뜨면 끝이에요. `server-code.html`에서도 "최신이에요"가 떠요.

빨간 X가 뜨면 눌러서 빨간 줄의 문구를 보면 이유가 나와요. 자주 있는 이유:

| 문구 | 할 일 |
| --- | --- |
| `User has not enabled the Apps Script API` | 1번(Apps Script API 켜기)을 해 주세요. 켜고 몇 분 뒤에 다시 돌려요 |
| `Requested entity was not found` / `permission` | 로그인한 구글 계정이 그 Apps Script 프로젝트의 주인이 아니에요. 프로젝트를 만든 계정으로 3번을 다시 해요 |
| `invalid_grant` | 로그인 정보가 만료되거나 취소됐어요. 3 · 4번을 다시 해요 |
| `코드 파일이 2개 있어요` | Apps Script 왼쪽 파일 목록에 `.gs` 파일이 하나만 있게 정리해요 |

## 알아 둘 것 (보안)

- `CLASPRC_JSON`은 그 구글 계정의 **Apps Script 프로젝트를 고치고 배포할 수 있는 열쇠**예요. GitHub 비밀값은 저장소 설정 화면에서도 다시 볼 수 없고, 작업 기록에도 가려져 나와요.
- 다만 이 저장소에 코드를 올릴 수 있는 사람은 자동 작업을 고쳐서 이 열쇠를 쓸 수 있어요. 저장소 협업자를 믿을 수 있는 사람으로만 두세요.
- 그만 쓰고 싶으면: https://myaccount.google.com/permissions 에서 **clasp** 접근을 삭제하고, GitHub 비밀값 두 개를 지우면 돼요.
