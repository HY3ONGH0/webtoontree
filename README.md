# 웹툰트리

웹툰을 처음 보는 사람이 게임 스킬트리처럼 웹툰을 하나씩 보며 흥미를 붙일 수 있게 만든 웹툰 추천 사이트예요.

사이트 주소: https://hy3ongh0.github.io/webtoontree/

## 지금 되는 것

- 홈: 장르 5개(판타지, 로맨스, 무협, 스릴러, 일상 · 힐링)를 장르 상징 별자리 카드로 보여 줘요
- 장르 트리: 웹툰 별자리, 하단 장르 띠, 관리자 강추 큰 별, 잠금/해금, 캐릭터 이동
- 상세 창: 작가·플랫폼·설명, 감상 진행(본 화수와 %), 이어 보기, 별점, 댓글, 다음으로 이어지는 웹툰
- 전체 지도: 마우스 드래그·휠, 손가락 드래그·핀치로 이동·확대, 검색, 미니맵
- 캐릭터 상점: 코인으로 장식·몸 색 구매와 착용
- 랭킹: 지금은 내 기록만 보여 줘요 (회원 기능 연결 후 친구 랭킹)
- 패드·휴대폰: 터치로 동작하고, 좁은 화면에서는 상세 창이 아래에서 올라와요

## 서버(Apps Script) 기능

`apps-script/Code.gs`를 구글 시트에 붙여 배포하고, 관리자 화면에 웹앱 주소를 넣으면 켜져요. 방법은 [apps-script/설치방법.md](apps-script/설치방법.md)에 있어요.

- 아이디·비밀번호 회원가입과 로그인 (비밀번호는 해시로 저장)
- 다른 사람과 함께 보는 평균 별점·댓글 (내 댓글 지우기, 관리자 숨기기)
- 계정에 저장되는 감상 진행·코인·상점 아이템, 서버에서 계산하는 코인
- 친구 랭킹 (이번 주·이번 달·전체 × 많이 본 화수·완독 수), 오늘 폭주
- 관리자 비밀번호 잠금 해제, "새 화 나왔어요" 제보, 매주 월요일 관리자 알림 메일
- 관리자 화면: 회원(정지·닉네임 변경·비밀번호 초기화), 댓글, 제보 관리, GitHub에 바로 저장
- 여러 관리자: 최종 관리자(`admin`)가 회원에게 관리자 권한을 주고 뺌, 관리자 화면은 함께 편집(몇 초마다 서로의 변경을 주고받음, 누가 어디를 고치는지 표시)

주소가 비어 있으면 지금처럼 이 브라우저에만 저장하는 "혼자 모드"로 동작해요.

| 파일 | 하는 일 |

| `index.html` | 사이트 첫 파일 |

| `js/app.js` | 데이터 불러오기, 주소 이동, 홈, 로그인 |
| `js/tree.js` | 장르 트리와 상세 창 |
| `js/map.js` | 전체 지도 |
| `js/shop.js` | 상점과 랭킹 |
| `js/store.js` | 기록 저장 (브라우저 저장소) |
| `js/api.js` | 서버(Apps Script) 연결 |
| `js/schedule.js` | 연재 요일·상태, 화수 자동 계산 |
| `js/layout.js` | 전체 지도 자동 배치 |
| `js/color.js` | 표지 색 뽑기, 상세 창 색 만들기 |
| `admin.html`, `js/admin.js`, `css/admin.css` | 관리자 사이트 |
| `apps-script/Code.gs` | 서버 코드 (구글 시트에 붙여 써요) |
| `js/character.js` | 캐릭터 그림 (직접 그린 그림으로 바꿀 곳) |
| `data/data.json` | 장르, 웹툰, 트리 연결, 전체 지도 위치, 상점 아이템, 사이트 설정 |

## 관리자 사이트

주소: https://hy3ongh0.github.io/webtoontree/admin.html

| 메뉴 | 할 수 있는 것 |
| --- | --- |
| 웹툰 목록 | 웹툰 추가·수정·삭제, 강추 지정, 총 화수, 연재 상태(연재 중·휴재·완결), 올라오는 요일, 화수 자동 계산, 트리·지도에 넣기 |
| 장르 관리 | 장르 추가·수정·삭제, 색, 별자리 모양, 입문작, 순서 |
| 트리 편집 | 노드 끌어서 옮기기, 가지 내리기, A → B 연결하기, 연결 이유, 자동 정렬 |
| 전체 지도 편집 | 웹툰 별과 장르 구역 옮기기, 연결선 추가·삭제, 트리 연결 가져오기 |
| 디자인 · 코인 설정 | 사이트 이름, 소개·공지 문구, 색, 애니메이션, 코인 규칙 |
| 상점 아이템 | 이름·가격·설명·NEW 표시, 아이템 추가·삭제 |
| 데이터 내보내기 | data.json 내보내기·불러오기, 미리보기, 확인할 것 목록 |

고친 내용은 그 브라우저에 초안으로 자동 저장되고, [사이트 미리보기](`index.html?preview=1`)로 올리기 전에 확인할 수 있어요.
사이트에 반영하려면 data.json을 내보내서 GitHub 저장소의 `data` 폴더에 올리면 돼요 (Add file → Upload files → Commit changes).

관리자 화면은 서버에 아무것도 바꾸지 않아서 주소를 아는 사람이 열어도 사이트는 바뀌지 않아요. 실제로 바꿀 수 있는 사람은 GitHub 저장소에 파일을 올릴 수 있는 사람뿐이에요.

## 웹툰 데이터 고치는 법

보통은 관리자 사이트에서 고치고 data.json을 내보내요. `data/data.json`을 직접 고쳐도 사이트에 바로 반영돼요.

- 웹툰 ID(`w001` 같은 값)는 한 번 정하면 바꾸지 않아요. 감상 기록이 ID로 연결돼 있어요
- `cover`에 이미지 주소를 넣으면 표지가 보이고, 비워 두면 제목 첫 글자가 보여요
- `color`는 상세 창 배경색이에요. 관리자 화면에서 표지 주소를 넣으면 표지에서 자동으로 뽑아 채워요 (직접 고를 수도 있어요). 비어 있으면 사이트가 표지에서 뽑아 써요. 다른 사이트 이미지는 브라우저가 색을 못 읽게 막아서, 그럴 땐 이미지 중계 서비스(images.weserv.nl)를 거쳐 색만 읽어요
- 장르 트리에 넣지 않은 웹툰은 그 장르의 **도서관**(트리 끝 아이콘)에 책으로 꽂혀요. 트리 끝 웹툰 중 하나를 완독하면 도서관이 열려요
- 장르에 **세부 장르**(`genres[].subs`)를 만들면 그 장르 도서관에 세부 장르별 마도서가 꽂혀요. 웹툰의 세부 장르는 `subs`(세부 장르 ID 목록)예요
- `recommended`는 관리자 추천 별 개수(0~5)예요. 예전처럼 `true`면 별 1개로 봐요
- `status`는 `ongoing`(연재 중) · `hiatus`(휴재) · `completed`(완결), `days`는 올라오는 요일(`mon`~`sun`)이에요
- `autoCount: true`면 연재 중일 때 `baseDate`(그날의 총 화수가 `episodes`) 다음 날부터 연재 요일마다 총 화수가 1씩 자동으로 늘어나요. 휴재로 어긋나면 관리자 화면에서 총 화수를 다시 적어 주면 돼요

## 기록 저장에 대해

지금은 기록(본 화수, 코인, 별점, 댓글)이 이 브라우저에만 저장돼요. 다른 기기나 다른 브라우저에서는 보이지 않고, 브라우저 데이터를 지우면 사라져요.
