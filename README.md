# 웹툰트리

웹툰을 처음 보는 사람이 게임 스킬트리처럼 웹툰을 하나씩 따라 보며 흥미를 붙일 수 있게 만든 웹툰 추천 사이트예요.

- 사이트: https://hy3ongh0.github.io/webtoontree/
- 관리자 화면: https://hy3ongh0.github.io/webtoontree/admin.html
- 서버 코드 복사 · 배포 확인: https://hy3ongh0.github.io/webtoontree/server-code.html

## 화면

위쪽 메뉴: **트리 · 도서관 · 요일 · 랭킹 · 전체 지도 · 프로필**

| 화면 | 주소 | 하는 일 |
| --- | --- | --- |
| 홈 | `#/` | 소개 문구와 시작 단추 |
| 트리 | `#/tree/장르` | 장르마다 입문작에서 가지를 뻗는 웹툰 트리. 잠금/해금, 캐릭터 이동, 관리자 강추 표시 |
| 도서관 | `#/library/장르` | 모든 웹툰이 책으로 꽂힌 책장. 장르 · 세부 장르, 검색, 작가 프로필. 트리가 없는 장르(아포칼립스 & SF)도 여기에는 나와요 |
| 도서관 목록 | `#/books` | 표지 목록. 장르 · 연재 상태 · 추천 별 · 내 기록 · 관심 웹툰으로 거르기 |
| 요일 | `#/week` | 연재작을 요일 칸에 표지로. 누르면 도서관처럼 옆에 상세 창. 맨 위 '오늘 볼 것'(오늘 올라오거나 새 화가 나온 내 웹툰), 새 화 배지, 보는 웹툰 · 관심 웹툰만 보기, 휴재 포함 |
| 랭킹 | `#/top`, `#/ranking`, `#/feed` | 이번 주 많이 읽은 웹툰, 독자 랭킹, 친구 소식(팔로우한 사람의 추천) |
| 회원 프로필 | `#/u/공개번호` | 다른 회원의 추천 · 관심 웹툰, 팔로우 (공개 범위: 전체 · 팔로워만 · 나만) |
| 전체 지도 | `#/worlds` | 장르 카드와 지도 |
| 작가 | `#/author/이름` | 작가의 웹툰, 네이버 작가 소식, 다른 작품 |
| 프로필 · 상점 | `#/me` | 내 기록 정리(이번 달 · 전체 본 화수, 다 본 웹툰, 연속 기록, 많이 본 장르), 공개 범위, 코인으로 캐릭터 꾸미기 |

웹툰을 누르면 상세 창이 열려요: 작가 · 플랫폼 · 설명, 감상 진행(본 화수), 이어 보기, 별점, 댓글, 관심 담기, 다음으로 이어지는 웹툰, 비슷한 웹툰, 친구에게 추천 · 링크 복사.

## 서버(Apps Script)

`apps-script/Code.gs`를 구글 시트의 Apps Script에 붙여 배포하고, 관리자 화면에 웹앱 주소를 넣으면 켜져요. 처음 설치는 [apps-script/설치방법.md](apps-script/설치방법.md)를 봐 주세요. 주소가 비어 있으면 그 브라우저에만 저장하는 "혼자 모드"로 동작해요.

- 회원가입 · 로그인, 계정에 저장되는 감상 진행 · 코인 · 상점 아이템 · 관심 웹툰
- 함께 보는 평균 별점 · 댓글, 랭킹, 오늘 폭주, "새 화 나왔어요" 제보
- 작품 연결: 공식 페이지에서 웹툰 정보를 가져오고 매일 새벽 다시 맞춰요 (아래 표)
- 작가 소식: 네이버 웹툰 작가 홈의 최근 공개 글 (미리보기 · 첫 사진 · 원문 링크)
- 관리자: 회원 · 댓글 · 제보 관리, GitHub에 바로 저장, 여러 관리자의 함께 편집

### 서버 코드를 고쳤을 때

사이트 파일은 GitHub에 합치면 자동으로 반영되지만, **서버 코드는 직접 붙여 넣고 배포해야** 바뀌어요.

1. [server-code.html](https://hy3ongh0.github.io/webtoontree/server-code.html)을 열면 지금 돌고 있는 서버가 최신인지 알려 줘요.
2. 예전 버전이면 코드를 복사해 Apps Script의 `Code.gs`에 전부 바꿔 붙이고 저장해요.
3. **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포** ("새 배포"를 누르면 주소가 바뀌어 사이트 연결이 끊겨요)
4. 같은 페이지에서 [다시 확인]을 눌러 "최신이에요"가 뜨면 끝이에요.

**버튼 배포(선택)**: [apps-script/자동배포.md](apps-script/자동배포.md)대로 한 번 설정해 두면, GitHub Actions 탭의 [Run workflow]로 위 1~4번을 대신할 수 있어요 (저절로 배포하지는 않아요).

서버가 예전 버전이면 관리자 화면 머리말에도 안내가 떠요. 서버 코드를 고칠 때는 `Code.gs`의 `SERVER_VERSION`과 `js/admin.js`의 `NEED_SERVER`를 함께 올려요.

## 관리자 화면

| 메뉴 | 할 수 있는 것 |
| --- | --- |
| 웹툰 목록 | 웹툰 추가 · 수정 · 삭제, 작품 연결, 강추 · 추천 별, 장르, 트리 · 지도에 넣기, 여러 편 추가(네이버 요일별 · 완결 목록, 제목 여러 줄, 카카오웹툰 검색) |
| 장르 관리 | 장르와 세부 장르, 색, 입문작, 순서 |
| 트리 편집 | 노드 옮기기, 가지 내리기, A → B 연결, 연결 이유, 간격 정리 |
| 전체 지도 편집 | 웹툰과 장르 구역 위치, 연결선 |
| 디자인 · 코인 설정 | 사이트 이름, 소개 · 공지 문구, 색, 코인 규칙, 서버 주소 |
| 상점 아이템 | 이름 · 가격 · 설명, 추가 · 삭제 |
| 회원 · 댓글 · 제보 | 관리자 연결, 회원 정지 · 권한, 댓글 숨기기, 제보 처리 |
| 데이터 점검 | 비공식 · 빈 보러 가기 링크, 외부 표지, 화수 이상, 장르 없음, 트리 밖, 연결 안 됨을 모아 보고 한꺼번에 고치기 |
| 저장 · 백업 | 사이트에 바로 저장, data.json 내보내기 · 불러오기 |

고친 내용은 그 브라우저에 초안으로 자동 저장돼요. 서버에 관리자로 연결하면 **[사이트에 바로 저장]**으로 올리고, 여러 관리자가 동시에 고쳐도 서로의 변경이 몇 초 안에 보여요(함께 편집).

## 고치고 올릴 때

```
node scripts/check.js
```

문법 오류, 깨진 데이터, 없는 파일 참조, 서버 · 관리자 화면의 판 번호 어긋남을 잡아요. GitHub에 올리면 같은 검사가 자동으로 돌아요(`.github/workflows/check.yml`).

화면에 쓰는 파일을 고쳤으면 `index.html` · `admin.html`의 `?v=` 번호를 함께 올려요 (브라우저가 예전 파일을 붙잡지 않게).

## 웹툰 데이터 고치는 법

보통은 관리자 사이트에서 고치고 data.json을 내보내요. `data/data.json`을 직접 고쳐도 사이트에 바로 반영돼요.

- 웹툰 ID(`w001` 같은 값)는 한 번 정하면 바꾸지 않아요. 감상 기록이 ID로 연결돼 있어요
- `cover`에 이미지 주소를 넣으면 표지가 보이고, 비워 두면 제목 첫 글자가 보여요
- `color`는 상세 창 배경색이에요. 관리자 화면에서 표지 주소를 넣으면 표지에서 자동으로 뽑아 채워요 (직접 고를 수도 있어요). 비어 있으면 사이트가 표지에서 뽑아 써요. 다른 사이트 이미지는 브라우저가 색을 못 읽게 막아서, 그럴 땐 이미지 중계 서비스(images.weserv.nl)를 거쳐 색만 읽어요
- 장르 트리에 넣지 않은 웹툰은 그 장르의 **도서관**(트리 끝 아이콘)에 책으로 꽂혀요. 트리 끝 웹툰 중 하나를 완독하면 도서관이 열려요
- 장르에 **세부 장르**(`genres[].subs`)를 만들면 그 장르 도서관에 세부 장르별 마도서가 꽂혀요. 웹툰의 세부 장르는 `subs`(세부 장르 ID 목록)예요
- `recommended`는 관리자 추천 별 개수(0~5)예요. 예전처럼 `true`면 별 1개로 봐요
- `status`는 `ongoing`(연재 중) · `hiatus`(휴재) · `completed`(완결), `days`는 올라오는 요일(`mon`~`sun`)이에요
- `autoCount: true`면 연재 중일 때 `baseDate`(그날의 총 화수가 `episodes`) 다음 날부터 연재 요일마다 총 화수가 1씩 자동으로 늘어나요. 휴재로 어긋나면 관리자 화면에서 총 화수를 다시 적어 주면 돼요

## 기록 저장에 대해

- 로그인하면 감상 진행 · 코인 · 별점 · 댓글 · 관심 웹툰이 계정(서버)에 저장돼 다른 기기에서도 보여요.
- "로그인 없이 둘러보기"로 쓰면 그 브라우저에만 저장돼요. 브라우저 데이터를 지우면 사라져요.
