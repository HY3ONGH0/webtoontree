# 웹툰트리

웹툰을 처음 보는 사람이 게임 스킬트리처럼 웹툰을 하나씩 보며 흥미를 붙일 수 있게 만든 웹툰 추천 사이트예요.

사이트 주소: https://hy3ongh0.github.io/webtoontree/

## 지금 되는 것

- 홈: 장르 5개(판타지, 로맨스, 무협, 스릴러, 일상 · 힐링)를 장르 상징 별자리 카드로 보여 줘요
- 장르 트리: 웹툰 별자리, 하단 장르 띠, 관리자 강추 큰 별, 잠금/해금, 캐릭터 이동
- 상세 창: 작가·플랫폼·설명, 감상 진행(본 화수와 %), 이어 보기, 별점, 댓글, 다음으로 이어지는 웹툰
- 전체 지도: 마우스 드래그·휠, 손가락 드래그·핀치로 이동·확대, 검색, 미니맵
- 캐릭터 상점: 코인으로 장식·몸 색 구매와 착용
- 랭킹: 지금은 내 기록만 보여 줘요 (회원 기능 연결 후 친구 랭킹)
- 패드·휴대폰: 터치로 동작하고, 좁은 화면에서는 상세 창이 아래에서 올라와요

## 아직 준비 중 (Apps Script 연결 후)

- 아이디·비밀번호 회원가입과 로그인 (지금은 "닉네임으로 시작"하면 이 기기에만 저장돼요)
- 다른 사람과 함께 보는 별점 평균·댓글, 친구 랭킹, 오늘 폭주 계산
- 관리자 비밀번호 잠금 해제, 관리자 사이트

## 파일 구조

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 사이트 첫 파일 |
| `css/style.css` | 모든 디자인. 맨 위 변수(`--gold`, `--node` 등)로 색·크기를 한 번에 바꿀 수 있어요 |
| `js/app.js` | 데이터 불러오기, 주소 이동, 홈, 로그인 |
| `js/tree.js` | 장르 트리와 상세 창 |
| `js/map.js` | 전체 지도 |
| `js/shop.js` | 상점과 랭킹 |
| `js/store.js` | 기록 저장 (지금은 브라우저 저장소) |
| `js/character.js` | 캐릭터 그림 (직접 그린 그림으로 바꿀 곳) |
| `data/data.json` | 장르, 웹툰, 트리 연결, 전체 지도 위치, 상점 아이템, 사이트 설정 |

## 웹툰 데이터 고치는 법

`data/data.json`을 고치면 사이트에 바로 반영돼요. 나중에는 관리자 사이트에서 고치고 이 파일로 내보내게 됩니다.

- 웹툰 ID(`w001` 같은 값)는 한 번 정하면 바꾸지 않아요. 감상 기록이 ID로 연결돼 있어요
- `cover`에 이미지 주소를 넣으면 표지가 보이고, 비워 두면 제목 첫 글자가 보여요
- `recommended: true`면 관리자 강추 큰 별이 붙어요
- 지금 들어 있는 웹툰 목록과 총 화수는 화면 확인용 예시예요

## 기록 저장에 대해

지금은 기록(본 화수, 코인, 별점, 댓글)이 이 브라우저에만 저장돼요. 다른 기기나 다른 브라우저에서는 보이지 않고, 브라우저 데이터를 지우면 사라져요.
