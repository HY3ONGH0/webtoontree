서버 코드 복사

Apps Script에 붙여 넣을 최신 Code.gs를 복사해요.

지금 돌고 있는 서버가 최신인지 확인하는 중…

  1. 위 버튼을 눌러 복사해요.
  2. 웹툰트리 구글 시트 → 확장 프로그램 → Apps Script를 열어요.
  3. Code.gs의 기존 코드를 전부 지우고 붙여 넣은 뒤 저장해요.
  4. 오른쪽 위 배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포
    ("새 배포"를 누르면 주소가 바뀌어 사이트 연결이 끊겨요)
  5. 아래 [다시 확인]을 눌러 초록색 "최신이에요"가 뜨면 끝이에요.

버튼이 안 되면 아래 칸을 길게 눌러 [전체 선택] → [복사]해 주세요.
