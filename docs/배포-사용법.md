# 웹툰트리 배포 · 사용법

오늘 저녁 배포할 때 위에서부터 순서대로 따라 하면 돼요. 뒤쪽은 관리자 3명이 쓰는 방법과 회원이 보는 기능 정리예요.

- 사이트: https://hy3ongh0.github.io/webtoontree/
- 관리자 화면: https://hy3ongh0.github.io/webtoontree/admin.html
- 서버 코드 복사 · 확인: https://hy3ongh0.github.io/webtoontree/server-code.html

---

## 1. 배포 순서 (서버 21판)

| 순서 | 할 일 | 확인 |
| --- | --- | --- |
| ① | GitHub에서 열려 있는 PR을 **Merge** 해요 | 1~2분 뒤 사이트에 반영돼요 (Actions의 초록 체크) |
| ② | [server-code.html](https://hy3ongh0.github.io/webtoontree/server-code.html)을 열어 "코드 판 번호"가 **21판**인지 봐요 | 20판이면 아직 반영 전이에요. 1~2분 뒤 새로고침 |
| ③ | **복사** 버튼 → Apps Script `Code.gs`의 내용을 전부 지우고 붙여 넣고 저장 💾 | |
| ④ | **배포 → 배포 관리 → ✏️ 연필 → 버전: 새 버전 → 배포** | "새 배포"를 누르면 주소가 바뀌어 사이트 연결이 끊겨요. 꼭 "배포 관리"로요 |
| ⑤ | server-code.html에서 **[다시 확인]** → "실행 중인 서버도 21판" | 안 바뀌면 ④를 다시 |
| ⑥ | 관리자 화면 맨 위에 "서버 코드가 예전 버전" 경고가 **없는지** 확인 | |

- 시트의 새 칸(`attend` `bio` `best` `claims`…)과 새 탭(`votes` `charVotes`)은 **자동으로 생겨요.** 직접 만들 필요 없어요.
- 문제가 생기면: 배포 관리 → 연필 → 버전에서 **바로 이전 버전**을 골라 배포하면 되돌아가요. (사이트 쪽은 GitHub에서 PR을 Revert)
- 서버 배포 전에 사이트만 먼저 올라가도 안전해요. 새 서버 기능(출석 · 투표 · 이벤트 · 프로필)만 "서버 코드가 예전 버전이에요"라고 안내하고, 나머지는 그대로 돼요.

### 배포 후 1분 점검

로그인한 상태로 차례대로 눌러 봐요.

1. 홈 → **출석 체크** 버튼을 누르면 코인이 올라가요
2. 프로필 → 꾸미기에서 배경 하나 구매 → 사이트 전체 배경이 바뀌어요
3. 랭킹 → **이달의 투표** 탭에서 한 표
4. 아무 웹툰 상세 창 → 별점 · 추천 · (캐릭터를 넣어 둔 작품이면) 최애 캐릭터
5. 관리자 화면 → 상점 아이템 · 시즌 편집 · 웹툰의 "내 별점"이 보여요
6. 도서관 메뉴(잠금 상태)가 자물쇠 표시이고, 누르면 트리로 보내져요

## 2. 관리자 3명 설정

별점은 **관리자마다 따로** 줘요. 그래서 3명이 각자 다른 계정으로 들어와야 해요.

1. 3명이 사이트에서 각자 회원가입해요.
2. **최종 관리자**가 관리자 화면 → **회원 · 댓글 · 제보** 탭에서 비밀번호로 연결 → 회원 목록에서 2명(또는 3명)을 **관리자로 지정**해요.
3. 지정된 관리자는 사이트에 로그인한 뒤 **프로필 → 관리자 화면 열기**로 들어와요.
4. 관리자 화면 안에서 **서버에 연결된 상태**여야 내 별점 · 강추를 줄 수 있어요 (연결 안 되면 입력칸이 잠겨요).

> ⚠️ 최종 관리자 비밀번호를 여러 명이 같이 쓰면 **한 사람으로 세어져요.** 별점은 꼭 각자 회원 계정으로 주세요.

## 3. 관리자 사용법

고친 내용은 그 브라우저에 **초안으로 자동 저장**돼요. 다 고친 뒤 **저장 · 백업 → 지금 내용으로 사이트에 바로 저장**을 눌러야 사이트에 올라가요.

### 3-1. 별점과 강추 (웹툰 목록 → 웹툰 선택)

| 항목 | 방법 | 사이트에 보이는 것 |
| --- | --- | --- |
| **내 별점** | 별 1~5개를 골라요. "안 줌"으로 내 별점을 뺄 수 있어요 | 관리자들이 준 별점의 **평균(반올림)** 이 최종 별점이에요 |
| **강추** | "내가 강추해요" 체크 | **한 명이라도** 강추하면 "관리자 강추"로 표시돼요 (별 대신 강추 표시) |
| 이전부터 있던 강추 | 예전에 달아 둔 강추는 "이전부터 있던 강추"로 남아 있어요 | 끄면 그 표시만 사라져요 |

- 박스 아래에 **누가 몇 점을 줬는지**와 **누가 강추했는지**가 보여요. 예: `효제 ★★★★★ · 유섭 ★★★★ · 형호 ★★ → 3.7 → ★★★★`
- 예전 별점은 모두 지웠고, 기존 강추 17편은 그대로 남아 있어요.
- 같은 웹툰을 두 명이 **동시에** 고치면 마지막에 저장한 쪽이 이겨요. 가능하면 서로 다른 웹툰을 나눠서 줘요.

### 3-2. 상점 아이템 (상점 아이템 탭)

종류를 눌러 걸러 봐요: **장식 · 몸 색 · 배경 · 트리 디자인**. 색이나 모양을 바꾸면 왼쪽 미리보기가 바로 바뀌어요.

| 종류 | 고를 수 있는 것 |
| --- | --- |
| 장식 | 모양 26종(왕관 · 산타 모자 · 복주머니 …), 몸 · 발 색 |
| 몸 색 | 몸 색, 발 색 |
| **배경** | 위 · 아래 색, 그림(별밤 · 노을 · 숲 · 바닷속 · 도시 · 우주 · 크리스마스 · 설날 · 추석 · 할로윈 · 여름 · 벚꽃 · 새해), 날리는 무늬(눈 · 별빛 · 꽃잎 · 낙엽 · 물방울 · 하트), 움직임, **직접 그린 그림 주소** |
| **트리 디자인** | 칸 테두리 색, 선 색, 칸 모양(원 · 둥근 네모 · 육각 · 마름모), 선 모양(실선 · 점선 · 점점이 · 빛나는 선) |

- **시즌 한정**: 아이템의 "시즌 한정" 칸에서 시즌을 고르면 **그 시즌 기간에만** 팔아요. 이미 산 사람은 계속 써요.
- 새로 만들기: 아래 `+ 장식 / + 몸 색 / + 배경 / + 트리 디자인` 버튼.
- 이미 산 사람이 있는 아이템을 지우면 그 사람의 착용이 기본으로 돌아가요.

### 3-3. 시즌 · 이벤트 (상점 아이템 탭 아래쪽)

| 시즌 | 당일 | 기본 기간 |
| --- | --- | --- |
| 새해 | 1월 1일 | 앞 3일 ~ 뒤 7일 |
| 설날 | 음력 1월 1일 | 앞 10일 ~ 뒤 3일 |
| 봄 벚꽃 | 4월 5일 | 앞 10일 ~ 뒤 3일 |
| 여름 | 8월 1일 | 앞 10일 ~ 뒤 3일 |
| 추석 | 음력 8월 15일 | 앞 10일 ~ 뒤 3일 |
| 할로윈 | 10월 31일 | 앞 10일 ~ 뒤 3일 |
| 크리스마스 | 12월 25일 | 앞 10일 ~ 뒤 3일 |

- **자동으로 바뀌어요.** 기간이 되면 사이트 배경이 시즌 배경으로 바뀌고, 처음 들어온 회원에게 알림이 떠요. 기간이 끝나면 회원이 고른 배경으로 돌아가요.
- 설날 · 추석은 음력이라 **2035년까지** 날짜를 넣어 뒀어요. (2036년 이후는 코드 `LUNAR`에 추가)
- 각 시즌마다 바꿀 수 있는 것: 사용 여부, 이름, 당일(월-일), 앞/뒤 며칠, 자동 배경, 미션 완료 보상 아이템, **미션 목록**(웹툰 N화 보기 · N일 출석 · N편 완독 · 추천 N개, 보상 코인).
- 시즌이 끝나는 날은 "당일 + 뒤 N일"이에요. 시즌 한정 아이템도 그때까지만 팔려요.
- 미션 이벤트 화면은 시즌 중에만 열려요 (`#/event`, 홈 화면의 "이벤트" 버튼).

### 3-4. 출석 체크 보상

상점 아이템 탭 맨 아래 **하루씩 받는 코인**에 쉼표로 적어요. 기본 `2, 2, 3, 3, 4, 4, 20` (7일째 보너스). 마지막 칸까지 받으면 처음으로 돌아가요. 하루 빠지면 1일부터 다시 시작해요.

### 3-5. 주요 캐릭터 (최애 캐릭터 투표용)

웹툰 선택 → **주요 캐릭터** 칸에 쉼표로 이름을 적어요 (최대 12명, 이름 12자까지). 비워 두면 그 웹툰에는 캐릭터 투표가 안 보여요.

- **위키백과에서 자동으로 찾기**: 그 웹툰의 한국어 위키백과 "등장인물" 항목에서 이름을 가져와요. **위키백과에 항목이 있는 작품만** 찾아져요.
- **캐릭터가 빈 웹툰 모두 찾기**: 빈 웹툰을 차례로 찾아요 (시간이 좀 걸려요).
- 자동으로 찾은 이름에는 단체 이름이나 엉뚱한 낱말이 섞일 수 있어요. **꼭 눈으로 확인하고 지워 주세요.**
- 회원은 이 목록에서만 고를 수 있어요 (직접 입력 불가).

### 3-6. 도서관 잠그기 (디자인 · 코인 설정)

**도서관 잠그기** 체크가 켜져 있으면:

- 트리 끝 웹툰 중 하나를 **완독해서 도서관 문을 연 사람**만 메뉴 · 홈 카드 · 도서관 목록으로 들어갈 수 있어요. (관리자는 항상 들어가요)
- 잠긴 사람이 누르면 "도서관은 잠겨 있어요" 안내와 함께 트리로 보내요. 메뉴에는 🔒 표시가 붙어요.
- 웹툰 상세 링크(친구 소식 · 공유 링크 · 요일 화면의 작품)는 그대로 열려요.
- **나중에 모두에게 열 때**: 체크를 끄고 저장하면 끝이에요.

### 3-7. 자주 쓰는 순서

1. 웹툰 추가 → 작품 연결(네이버 · 카카오 검색)
2. 장르 · 트리 위치 정하기
3. 주요 캐릭터 넣기
4. 내 별점 / 강추
5. **사이트에 바로 저장**

## 4. 회원이 쓰는 기능

| 기능 | 위치 | 설명 |
| --- | --- | --- |
| 트리 | 메뉴 → 트리 | 장르별로 입문작부터 따라 보는 웹툰 지도. 끝 웹툰을 완독하면 도서관이 열려요 |
| 화수 기록 · 코인 | 웹툰 상세 창 | 1화당 1코인(하루 50화까지), 완독 보너스 20코인 |
| **출석 체크** | 홈 · 프로필 | 매일 1번, 연속 7일째 보너스. 기록 달력에 출석한 날이 표시돼요 |
| **꾸미기** | 프로필 → 꾸미기 | 장식 · 몸 색 · **배경** · **트리 디자인**. 배경은 사이트 전체에 깔려요 |
| **시즌** | 자동 | 시즌이 되면 배경이 바뀌고 알림이 떠요. 꾸미기에서 "시즌 배경 자동으로 보기"를 끌 수 있어요. 한정 아이템은 "시즌 한정" 탭에서 |
| **이벤트 미션** | 홈 · `#/event` | 시즌 중 미션을 깨고 코인 + 한정 아이템 받기 |
| **이달의 웹툰** | 랭킹 → 이달의 투표 | 한 달에 한 표, 마감 전까지 바꿀 수 있어요. 역대 1위도 볼 수 있어요 |
| **최애 캐릭터** | 웹툰 상세 창 | 웹툰마다 한 표, 다른 캐릭터를 누르면 바뀌어요 |
| **프로필 꾸미기** | 프로필 → 공개 프로필 꾸미기 | 소개글(60자) + 최애 웹툰 3편. 공개 프로필 위에 배경과 캐릭터가 보여요 |
| 친구 | 랭킹 → 친구 소식 | 닉네임으로 찾아 팔로우, 팔로워 · 팔로잉 목록 |
| 공개 범위 | 프로필 | 전체 · 팔로워만 · 나만 |
| 기록 이어 보기 | 자동 | 새 화 표시와 본 기록이 계정에 저장돼 다른 기기에서도 이어져요 |
| 안내 | 홈 맨 아래 | 소개 · 이용약관 · 개인정보 안내 (`#/about`) |

## 5. 막혔을 때

| 증상 | 확인 |
| --- | --- |
| 화면이 예전 그대로예요 | 브라우저 새로고침(아이패드는 탭을 닫았다 열기). 파일을 고쳤다면 `index.html` · `admin.html`의 `?v=` 번호를 올렸는지 |
| "서버 코드가 예전 버전이에요" | 1번의 ③~⑤ |
| 출석 · 투표 · 이벤트가 "알 수 없는 요청" | 서버 21판 배포 전이에요 |
| 별점 칸이 회색이라 못 눌러요 | 관리자 화면에서 서버에 연결하지 않은 상태. 최종 관리자는 비밀번호로 연결, 나머지는 사이트 로그인 후 "관리자 화면 열기" |
| 시즌 배경이 안 바뀌어요 | 시즌의 **사용** 체크 · 기간 · **자동 배경** 지정 확인. 회원 쪽은 꾸미기의 "시즌 배경 자동으로 보기" |
| 도서관이 안 열려요 | 설정의 "도서관 잠그기"를 끄면 모두에게 열려요 |
| 캐릭터 자동 찾기가 "찾지 못했어요" | 위키백과에 그 작품의 등장인물 항목이 없는 경우예요. 직접 적어 주세요 |
| 저장했는데 사이트에 안 보여요 | GitHub Pages 반영에 1~2분 걸려요 |
| "다른 관리자가 그사이 사이트에 먼저 저장했어요" 경고 | 지금 내용으로 저장하면 그 사람 내용이 사라져요. 안내에 있는 **최신 내용 불러오기**를 먼저 하고 다시 고쳐요 |
